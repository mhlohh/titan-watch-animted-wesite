# Titan Skeleton Automatic - Premium Landing Page

A highly interactive, cinematic web experience designed to showcase the Titan Skeletal Automatic watch (Model NT90110QM01). Moving away from traditional e-commerce templates, this project focuses entirely on brand heritage and product engineering through an immersive, Apple-style scroll animation sequence.

### Tech Stack
* **Framework:** React + Vite
* **Styling:** Tailwind CSS (Custom Luxury Theme)
* **Animation:** Framer Motion + HTML5 Canvas (60fps Image Sequencing)
